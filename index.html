libmas

Collection of minimal assemblers.

Building

Currently, only ARM Thum-2 platform back end is implemented. You can directly build this project using make -j if you are on an ARM computer. To cross-compile from another CPU architecture, you can install GNU ARM cross-compiler: 

            # vvv your operating system's ARM cross-compiler
export CC=arm-linux-gnueabi-gcc
export AR=arm-linux-gnueabi-ar
make -j
