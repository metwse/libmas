Parse and consume the next argument lexeme.

Advances inst to end of the opcode on success.

Parameters
instPointer to the remaining instruction string.
opcodeOpcode of the parsed instruction.
op_seminfoExtra semantic information for the parsed instruction.
out_arg_lexemeOutput buffer for the parsed argument lexeme.
argpVariable arg list pointer to consume by lexer.
Returns
NULL on success, (void *) -1 if the instruction fully consumed and there is no output, or error pointer on failure.
